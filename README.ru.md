# Boat Dashboard

[English](README.md) | [Suomi](README.fi.md) | [Svenska](README.sv.md) | **Русский** | [Deutsch](README.de.md)

Небольшое веб-приложение, в котором судовой журнал собран в одном месте: рейсы и публичный журнал, моточасы, обслуживание, расходы, документы, датчики и несколько лодок, если они нужны.

Это приложение на Flask с базой SQLite. Отдельный сервер базы данных не нужен. У каждой лодки свой файл базы, поэтому лодку можно скопировать или сохранить отдельно.

**Описание для GitHub (About):**  
Личный судовой журнал: рейсы, моточасы, обслуживание, расходы, документы и датчики. Одна команда создаёт рабочую установку. SQLite, без внешней базы данных.

## Что умеет приложение

- Вход по имени пользователя и паролю. Перед страницей входа можно потребовать код доступа, и администратор может отключить этот шаг.
- Несколько лодок и выбор, кто может открыть каждую из них.
- Журнал рейсов, публикация записи и одобрение или удаление публичных комментариев до того, как их увидят.
- Учёт моточасов, интервалов обслуживания, чек-листа на борту и пассажиров.
- Расходы с фото чеков, документы и заметки.
- Температура, влажность и уровень трюмной воды, которые присылает датчик.
- Язык интерфейса: английский, финский, шведский, русский и немецкий.
- Фото уменьшаются при загрузке (длинная сторона не больше 1600 px), чтобы снимки с телефона не заполняли диск.

## Что нужно

- Python 3.10 или новее
- pip

Проверка:

```bash
python3 --version
```

В Windows можно использовать `py --version` или `python --version`.

## Новая установка

Эти шаги создают пустую панель с одной лодкой и учётной записью администратора.  
**Не делайте этого, если у вас уже есть база, которую нужно сохранить.** Тогда смотрите раздел [Перенос существующей лодки](#перенос-существующей-лодки).

### 1. Получите файлы

```bash
git clone https://github.com/YOUR_USER/boat_dashboard.git
cd boat_dashboard
```

### 2. Создайте виртуальное окружение и установите пакеты

macOS и Linux:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Windows (командная строка):

```bat
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Создайте первую базу

```bash
python fresh_start.py
```

Скрипт удаляет `main.db` и папку `boats/` в этом каталоге, затем создаёт:

| | |
|---|---|
| Код доступа | `1234` |
| Имя пользователя | `admin` |
| Пароль | `admin123` |
| Лодка | My First Boat, назначена пользователю `admin` |

Смените пароль после первого входа. Добавьте свой код в разделе **Secure Codes**, затем удалите `1234`.

### 4. Разрешите вход на своём компьютере

Приложение настроено для сайта с HTTPS. По адресу `http://localhost` браузер не сохраняет cookie входа, поэтому страница пароля просто обновляется и войти не получается.

Откройте `app.py` и только для локальной проверки замените:

```python
app.config['SESSION_COOKIE_SECURE'] = True
```

на:

```python
app.config['SESSION_COOKIE_SECURE'] = False
```

Верните `True`, когда сайт работает по HTTPS.

### 5. Запуск

```bash
python app.py
```

Откройте [http://localhost:5000](http://localhost:5000).

## Ежедневная работа

1. Введите код доступа, если этот шаг включён.
2. Войдите в систему.
3. Выберите лодку. На главной странице показаны моточасы, датчики и галерея лодки.
4. В боковом меню: журнал, история мотора, обслуживание, чек-лист, пассажиры, заметки, расходы, документы и сведения о лодке.

**Публичный журнал.** В настройках журнала его можно опубликовать. Гости открывают его по адресу:

```text
http://localhost:5000/<имя-лодки>/journal
```

Пробелы в имени лодки заменяются дефисами, имя пишется строчными буквами. Лодка `My First Boat` публикуется по адресу `/my-first-boat/journal`. Комментарии к публичной записи скрыты, пока вы не откроете запись под своим входом и не нажмёте **Approve**.

**Код доступа включён или выключен.** Войдите как администратор, откройте меню пользователя и выберите **Secure Codes**. Переключатель вверху включает или выключает дополнительный код. Выключение не удаляет сами коды.

**Добавить человека.** Администратор может создать пользователей и назначить их на лодку. Пользователь видит только те лодки, к которым его привязали.

**Резервная копия.** На странице лодок администратора можно скачать zip с базой одной лодки и загруженными файлами. Сохраните также копию `main.db`. В zip нет учётных записей пользователей.

## Перенос существующей лодки

Данные лодки лежат в трёх местах. Для лодки с номером 2 это файлы:

| Скопируйте | В новую папку | Что внутри |
|---|---|---|
| `main.db` | `main.db` | пользователи, пароли, коды доступа, список лодок |
| `boats/boat_2.db` | `boats/boat_2.db` | рейсы, моточасы, расходы, заметки |
| `static/uploads/boat_2/` | `static/uploads/boat_2/` | фото, документы, чеки |

Не переименовывайте `boat_2.db` в `boat_1.db`. Число — это номер лодки, и пути к фото в базе используют то же число.

Затем в новой папке:

```bash
pip install -r requirements.txt
python migrate_db.py
python app.py
```

`migrate_db.py` добавляет недостающие таблицы и столбцы. Он не удаляет рейсы, пользователей и номера лодок. При первом запуске также создаются `main.db.bak` и `boats/boat_2.db.bak`.

**Не** запускайте `fresh_start.py` в папке, где уже лежит старый `main.db`. Этот скрипт удаляет старые базы.

Войдите со старым именем, паролем и кодом доступа.

## Показания датчиков

Устройство может отправить JSON на `POST /api/sensor`:

```json
{
  "boat_id": 2,
  "secret": "the-secret-set-for-this-boat",
  "temperature": 18.2,
  "humidity": 61,
  "bilge_level": 0
}
```

Секрет задаётся на странице лодки у администратора. Неверный секрет отклоняется.

```text

├── app.py              # запускает Flask
├── routes.py           # страницы и API датчиков
├── models.py           # схема SQLite и обновления

├── fresh_start.py      # пустая установка (удаляет старые данные)

├── templates/          # страницы
├── static/             # значки и загрузки во время работы
├── boats/              # boat_1.db, boat_2.db, … (не в git)

```

## Настройки

`config.py` читает такие параметры:

| Параметр | Смысл |
|---|---|
| `SECRET_KEY` | Задайте эту переменную окружения на сервере. Не оставляйте ключ по умолчанию на публичном сайте. |
| `TIMEZONE` | «Сейчас» в журналах. По умолчанию `Europe/Helsinki`. |
| `ALLOWED_EXTENSIONS` | png, jpg, jpeg, gif, webp, pdf, gpx |
| `MAX_CONTENT_LENGTH` | 25 МБ на одну загрузку, то же задано в `app.py` |

Созданные файлы перечислены в `.gitignore`: `*.db`, `boats/`, `static/uploads/`, `logs/` и виртуальные окружения. Не добавляйте их в git. В них пароли, личные рейсы и фотографии.

## Публичный сервер

- Работайте через HTTPS и оставьте `SESSION_COOKIE_SECURE = True`.
- Смените пароль администратора и код доступа.
- Задайте длинный случайный `SECRET_KEY`.
- `python app.py` запускает сервер разработки Flask (`debug=True`). Для публичного сайта запускайте приложение через WSGI-сервер, например gunicorn, за nginx или Caddy.
- Сервер разработки слушает все интерфейсы, порт 5000.
